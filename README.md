<ol>
  <li>禁止骚扰我</li>
  <li>禁止使用一键发评论和弹幕</li>
  <li>点赞时，禁止使用一键发评论和弹幕</li>
  <li>禁止发各种定位空降评论</li>
  <li>禁止发各种无意义垃圾评论</li>
  <li>禁止发各种无意义图片评论</li>
  <li>不允许私信发无意义某商业内容</li>
  <li>禁止盗我的视频和频道资料</li>
  <li>禁止重复关注及刷私信</li>
  <li>不允许私信刷屏</li>
  
</ol>

</ol>
